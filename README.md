Lumen Harvest — Starfall Orchard is an original, offline browser arcade catcher. Catch falling star shards, dodge void meteors, chain combos, level up and reach 500 points to win. Three lives, golden comets, and a best score saved on your own computer only — no network, no images, no external libraries.

## Run it

```sh
node main.ts
# then open game/index.html in desktop Chrome
```

## How to play

- Move: Arrow keys / WASD, or mouse (the basket follows the pointer)
- Space: dash (a short speed burst)
- P: pause · M: mute · R: restart · Enter: start
- Star shard +10 (combo multiplies) · Golden comet +50 and +1 life (max 5) · Void meteor −1 life
- Every 100 points the fall gets faster. Win at 500 points.
